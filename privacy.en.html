LottoNote Privacy Policy

Local records

Entered draw records, saved combinations, labels, timestamps and analysis snapshots stay in the app’s local storage. The current app has no operator server, account or cloud synchronization. Its storage directory is configured to be excluded from automatic device backup.

Sharing and files

When you choose to share, only the selected combination and label are supplied to the iOS share sheet. You select the destination and recipient. Copying happens only when you tap the copy button. The app checks only the KakaoTalk URL scheme for availability and does not read contacts. Imports use the system document picker; exported backups include personal records. Files or messages sent to another provider are governed by that provider’s policy.

Retention and deletion

Delete individual combinations or use the app’s delete-all control to remove local records and the internal recovery copy. Exported files and messages in other apps are not removed automatically.

Tracking

The current release candidate has no ads, advertising identifiers, analytics SDKs, operator account, friend network or CloudKit synchronization. Apple device diagnostics follow Apple policies. These declarations must be reviewed before adding new SDKs or cloud features.

Contact

Contact: seogihyun@gmail.com. If you choose to email support, your sender address and message are delivered to this support mailbox. The app does not send support emails automatically. Do not send passwords, authentication codes or a complete private record history. Email handling by the email provider follows that provider’s policy.

Website hosting

This privacy and support site is hosted by GitHub Pages. GitHub logs and stores visitors’ IP addresses for security purposes. The operator has not added analytics scripts, ads or input forms to this site. See GitHub Pages documentation for details.
